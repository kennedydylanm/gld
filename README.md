# Dylan Kennedy | GLD Portfolio

My Graduation with Leadership Distinction ePortfolio for the University of South Carolina, in the Professional Engagement pathway.

**Live site** https://kennedydylanm.github.io/gld/

I'm a chemical engineering student in the Honors College. The site covers my three Key Insights, my leadership proposal from my time at Enviva, and a few engineering projects, each with the original documents linked as PDFs.

## How it's built

The whole site is one hand-written HTML file with plain CSS and JavaScript, so there's no framework or build step. The sky moves from day to night as you scroll, and a few small touches react to the real date and time.

## Folders

| Folder | What's in it |
| --- | --- |
| `index.html` | The site |
| `images/` | Photos, project images, and artifact previews |
| `files/` | PDFs of my artifacts and projects, plus my resume |
| `fonts/` | Font files and their license |
| `audio/` | Background music and click sounds |
